# agent-pulse (Python)

The Python implementation of [agent-pulse](https://github.com/knowall-ai/agent-pulse): report what
your AI agent does as `AgentActivity` events to its own Application Insights. Standard library
only, Python 3.10+.

```
pip install "agent-pulse @ git+https://github.com/knowall-ai/agent-pulse#subdirectory=python"
```

See the [main README](https://github.com/knowall-ai/agent-pulse#readme) for usage and the
[AgentActivity v1 contract](https://github.com/knowall-ai/agent-pulse/blob/main/spec/AGENT-ACTIVITY.md).
